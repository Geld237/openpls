OpenPLS — PLS-SEM libre et gratuit (Linux)
==========================================

Lancer : double-cliquez sur « OpenPLS » dans ce dossier (ou ./OpenPLS dans un terminal).
OpenPLS s'ouvre dans votre navigateur ; pour quitter, cliquez « Quitter OpenPLS »
dans la barre latérale.

Fenêtre d'application : si votre système dispose de Qt (paquet python3-pyqt6.qtwebengine
ou équivalent), une installation via pip (« pip install openpls[gui,desktop] pyqt6-webengine »)
ouvre OpenPLS dans sa propre fenêtre.

Vos données restent sur votre ordinateur : rien n'est envoyé sur Internet.

Aide et code source : https://github.com/Geld237/openpls
